# Snake Game

A simple Snake Game built using HTML, CSS, and JavaScript.

## Features
- Score tracking system
- Start and Restart functionality
- Works on both mobile and desktop
- Grid-based game layout

## What I Learned
- Game loop management
- Event handling
- Collision detection
- DOM manipulation
- State management and UI synchronization

## Challenges Faced
Keeping the snake movement, food generation, and score updates in sync. Small mistakes could break the entire game logic.

## How to Run
1. Download or clone this repository
2. Open project.html in your browser
